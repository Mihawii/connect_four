# Inferno

Быстрый Connect Four, где фишки живут недолго. Каждая твоя фишка держится десять твоих ходов, на одиннадцатом сгорает, сверху всё падает вниз. План меняется каждые пару ходов, и это весело.

**Три режима:** Classic, Inferno и Inferno Blitz.

**Что внутри:**
- локальная игра и бот
- комнаты для друзей
- дневная головоломка
- уроки по тактике
- ладдер
- AI-тренер после партии
- магазин скинов и Pro

Доска в 3D: фишки падают с весом, сгорание выглядит как настоящий жар.

## Быстрый старт

```bash
npm install
cp .env.example .env.local
npm run dev
```

Открой http://localhost:3000. Без ключей уже можно играть локально. Авторизация, мультиплеер, тренер и оплата подключаются через `.env.local`.
